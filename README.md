# ⚡ Zepto Sales & Delivery Performance Dashboard

An interactive Power BI and Excel data analytics project analyzing Zepto's quick-commerce grocery delivery data, sales trends, and order fulfillment metrics.

---

## 🚀 Project Overview
The primary objective of this project is to analyze Zepto's order and sales performance, examine category-level revenue, track order volume, and evaluate delivery efficiencies across various locations.

---

## 🛠️ Tools & Technologies Used
* **Power BI:** Data Modeling, DAX Measures, Interactive Visualizations & KPI Cards
* **Microsoft Excel:** Data Cleaning, Transformation, and Pre-processing

---

## 📈 Key Insights & Features
* **Revenue & Sales Metrics:** Comprehensive overview of total revenue, average order value, and sales growth.
* **Category Performance:** Identification of high-demand grocery items and category-wise sales contribution.
* **Delivery Performance:** Analysis of delivery timings, fulfillment rates, and operational efficiency.
* **Interactive Dashboard:** Slicers for item category, dates, and order status for granular data exploration.
